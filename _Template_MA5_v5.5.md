   - Include short excerpts or links if helpful.

3. **Handle raw research notes like this**  
   - Keep full/raw notes in a folder (don't bury them—archive them for reference).  
   - Only share a distilled version with the MA5 council.  
   - If needed, attach 1-2 polished files max to Clarification Phase (e.g., one summary markdown).  
   - No raw dumps—prevents overload and keeps all Sherpas starting equal.

4. **Start the council**  
   - Create fresh threads for each Sherpa.  
   - Paste the identical polished Initial Presentation into "Daniel's Initial Presentation" in Clarification Phase.  
   - All five Sherpas now probe from the same clean starting point—full parallel rivalry.

****Why this way**  
	- Equal info for all Sherpas (no bias).  
	- Less friction for carbon (prep once, distill once).  
	- Cleaner meetings (no phase confusion or overwhelm).
