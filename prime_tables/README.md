# Initium PrimeTables

One markdown file per prime (100 files). YAML frontmatter holds prime, tag, dice, suit, SUMMARY, sherpa_version, and expert slopes. Body is the KB card record.

These are the playable card records. They are not the print-spread transcriptions in [`../spreads/`](../spreads/) (those keep the `_spread.md` suffix and the verso/recto extract from the PDF).

Filenames keep the Initium tag (`P.` / `S.` / `T.` / `W.`), camp code, and monomyth stage slug.

The four suit tables that Asker parses live in [`../suits/`](../suits/).
