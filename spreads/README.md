# Initium Prime Spread Markdown

One markdown file per Initium prime card spread (100 files). Extracted text from the print spreads for citation, Asker enrichment, and silicon digesters. License: CC BY-NC-SA 4.0 (same as Scotomaville / Initium corpus).

Print PDFs remain under [`pdf/spreads/`](../pdf/spreads/). Prefer the PDF when the claim rests on the printed card face; prefer this markdown when an agent or paper needs searchable text.

## Stable paths

Raw GitHub (cite from section papers / AISM answers):

`https://raw.githubusercontent.com/scotomaville/initium/main/spreads/Initium_Prime_NNN_*.md`

Browse: [spreads/](https://github.com/scotomaville/initium/tree/main/spreads)

Example (Echo Dampener):

- Markdown: [Initium_Prime_151_Echo_Dampener_T.151.C02.crevasse_spread.md](https://raw.githubusercontent.com/scotomaville/initium/main/spreads/Initium_Prime_151_Echo_Dampener_T.151.C02.crevasse_spread.md)
- PDF: [Prime_151.pdf](https://raw.githubusercontent.com/scotomaville/initium/main/pdf/spreads/Prime_151.pdf)

## Naming

Filenames keep the Initium tag (`P.` / `S.` / `T.` / `W.`), camp code, and monomyth stage slug so a link names the card without opening the file.
