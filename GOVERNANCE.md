# IPG MANIFESTO — GOVERNANCE

## Amendment Authority

The Carbon Steward (Daniel J. Comp) holds sole amendment authority over the IPG Manifesto and all governing documents in this repository.

Substantive changes require MA5 Council consultation (Grok + Claude at minimum). Minor corrections (sourcing, formatting, typos) may be made by Carbon Steward alone.

## Version Trail

All versions are maintained via Git commit history. Version naming:
- `v1.x` — minor revisions; co-signatures carry forward if architecture is unchanged. v1.5 is this class: two operational insertions; co-signs cover the unchanged v1.4 architecture only; insertions pending axial/council re-sign.
- `v2.0` — structural revision requiring full council re-sign

## Co-Signature Protocol

Co-signatures are valid for the version signed. New versions above v1.x require fresh council review. Co-sign share links are preserved in `SOURCES.md` for provenance.
