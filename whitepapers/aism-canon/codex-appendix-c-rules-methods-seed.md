## Summary

Appendix C is the **session header seed** for how carbon and silicon extract, document, and transmit formation material. It lists key protocol elements still marked for full Stage 3 documentation: MoltBook overnight corpus push, extraction flag taxonomy, error correction without losing formative content, State File handoffs, carbon somatic veto, and MA5 Council consultation. **Parallel Relay** is inserted as a **field observation** (cases logged 2026-09-26), not a general theorem — under Babel Echo attribution and carbon veto. Handoff ownership and logging are named (see D3.2).
