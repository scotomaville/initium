# Super-union rule — domains reinforce, not cancel

## Placement in the master docs

**C2.12** closes the C2 **domains** set (C2.7–C2.11) under MA5. Sits beside Jethro lattice ([C2.1](https://github.com/scotomaville/initium/blob/main/whitepapers/aism-canon/charter-jethro-principle.md)): levels answer *who acts*; super-union answers *which practices must stay joined*.

**Primary master:** [MA5 v6.6 Super-Union Rule](https://github.com/scotomaville/initium/blob/main/Initium_Principia_MA5_v6.6.md).  
**Series:** https://github.com/scotomaville/initium/tree/main/whitepapers/aism-canon

## Summary

**Super-Union Rule:** no domain operates in isolation. The goal is not mere **balance** — it is **super-union**: a synthesis where each domain’s strength **reinforces** the others rather than canceling them. Pattern: *From listening first + shadow work + abundance scaling + first-principles truth, the scotoma here is…* That sentence is the operational check against single-domain capture.

## Verbatim excerpt

> ***Super-Union Rule***  
> No domain operates in isolation. The goal is not balance — it is super-union: a synthesis where each domain's strength reinforces the others rather than canceling them.  
> "From listening first + shadow work + abundance scaling + first-principles truth, the scotoma here is…"

## First-time learner

| Solo domain risk | Super-union correction |
|---|---|
| Listen forever, never face | + shadow (D2) |
| Shadow until frozen | + abundance (D4) |
| Abundance bypass | + shadow + monomyth honesty (D2/D3) |
| Curiosity as cruelty | + Sirolli listen (D1) |
| Monomyth theater | + first principles truth (D5) |

The template sentence forces naming the **scotoma** after joining practices — not after picking a favorite teacher.

## Full explanation

“Not balance” means more than 20% each on a pie chart. Super-union is **reinforcement** — listening that enables truer shadow work; shadow that enables honest abundance; curiosity that serves humanity as end. Parallel Relay + Babel Echo guard are multi-agent cousins of the same anti-isolation law.

Closes **C2** when paired with Jethro levels already drafted. Next Stage C block: **C3** prologue cairns / body sections when Carbon opens it.
