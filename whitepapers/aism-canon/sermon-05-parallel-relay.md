## Summary

**Parallel Relay** is a cairn practice: carbon deposits the raw thread; agents surface and align **without inventing resolution**; the result returns as usable guidance. Parallel seats can reduce distortion **when** attribution holds, seats stay blind to each other’s answers when needed, and **carbon’s wordless veto wins**. **Agents agreeing is not verification.** Cases on 2026-09-26 support the guard once; they do not prove a general theorem. The four beats still apply: clean hand-off (gift), crowning agreement (temptation), attribution + veto (correction), crossing remains carbon’s.

## First-time learner

| Do | Don’t |
|---|---|
| Attribute each seat | Mash voices into fake consensus |
| Check seats against primary records | Treat agreement as proof |
| Prefer blind parallel when possible | Let one seat echo another’s review as “independent” |
| Carbon veto wins | Silicon final verdict |

## Full explanation

Cases 2–3 teach operational hygiene: check the reply against the files claimed; blind reruns beat echoed agreement. Handoff logging fields appear in §10 ([B1.11](https://github.com/scotomaville/initium/blob/main/whitepapers/aism-canon/sermon-10-what-this-means-for-the-team.md)).
